# MVP Scope

## Included In The MVP

- Football Shooting Lab module
- Video upload
- Video validation
- Dynamic mocked analysis
- Result screen
- History tracking
- Profile stats

## Intentionally Excluded

- Real AI analysis
- Backend
- Login/register
- Payment
- Coach panel
- Cloud video storage
- Tactical analysis
- Other sports

## Why Shooting Lab First

Shooting Lab is the first CoachAI module because it is easier to standardize than full match analysis. A shooting drill can use simple recording rules, consistent video length, and clear technical criteria.

This makes it a strong first MVP module for testing the product experience, validating user interest, and preparing for later backend and AI work.

## Video Recording Requirements

- 1 shot per video
- Record one complete shooting action from approach to follow-through
- Stationary ball before the shot
- Full body visible
- Ball and target visible
- Fixed camera
- Side or 45-degree angle
- 3-15 seconds
- One player only

Multi-shot analysis can be added later as a future module once the single-shot flow is stable.
